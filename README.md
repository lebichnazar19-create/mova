# Мова

Українська мова програмування з власним байткодом і стековою VM. Компілятор
і VM написані на Python 3.11+, працюють у Termux на Android. Керування
залізом пристрою (вібрація, сповіщення, батарея, ліхтарик тощо) — через
`termux-api`. Локальна LLM (ollama / llama.cpp) підключена як вбудована
функція мови (`спитай`, `переклади`, `стисни`).

## Встановлення

```bash
pkg update && pkg upgrade -y
pkg install python termux-api -y
```

Тести (pytest) в Termux/proot-Ubuntu найпростіше поставити через apt, бо
`pip` тут не завжди доступний/справний:

```bash
apt install -y python3-pytest   # або: pip install pytest — де pip є
```

Окремо постав Android-застосунок **Termux:API** з F-Droid (з того самого
джерела, що й сам Termux). Перевір міст:

```bash
termux-vibrate -d 300
termux-notification -t "тест" -c "працює"
```

## Використання

```bash
python3 мова.py                          # інтерактивний режим (REPL)
python3 мова.py програма.мова            # скомпілювати і виконати
python3 мова.py -к програма.мова         # скомпілювати -> програма.байт
python3 мова.py -б програма.байт         # виконати готовий байткод
python3 мова.py -д програма.мова         # показати дизасембльований байткод
python3 мова.py -л "вібруй тричі, якщо заряд нижче двадцяти"   # з людської мови в код

python3 мова.py --без-пристрою програма.мова   # без реального заліза — для тестів/CI
```

Або признач права на виконання і клич без `python3`:

```bash
chmod +x мова.py
./мова.py програма.мова
```

## Структура

```
yadro/
  ключові.py      — таблиця українських ключових слів
  лексер.py        — текст -> токени (блоки за відступами, як у Python)
  аст.py           — вузли AST
  парсер.py        — токени -> AST
  компілятор.py    — AST -> байткод
  вм.py            — стекова VM, що виконує байткод
  вбудовані.py     — реєстр імен нативних функцій (спільний для компілятора й VM)
  пристрій.py      — єдине місце з subprocess; обгортки над termux-*
  розум.py         — міст до локальної LLM (ollama/llama.cpp)
  малюнок.py       — малювання у SVG-файл: накопичує фігури, покажи()
                      робить HTML+SVG і відкриває через пристрій.відкрий()
  екран.py         — малювання прямо в терміналі (ANSI 24-bit) + тримай()
                      (живий режим з перемальовуванням при зміні розміру)
  креслення.py     — режим креслення (спрощене ЄСКД): контур/розміри/види,
                      3D-лінії з проєкціями (зверху/спереду/збоку/ізо),
                      теми "папір"/"друк"; вивід так само у SVG, своя покажи()
  ескіз.py         — параметричний ескіз (вузол/сегмент + прив'язки:
                      вертикально/горизонтально/рівні/довжина/кут_між/
                      збіг/на_лінії) і розвяжи() — числовий розв'язувач
  fayly.py         — файлові функції мови (прочитай_файл/запиши_файл/
                      допиши_файл/є_файл), відносні шляхи від теки ВМ
  дизасемблер.py   — людський вивід байткоду
  помилки.py       — ПомилкаРозбору / ПомилкаКомпіляції / ПомилкаВиконання
тести/             — pytest
приклади/          — .мова файли, зокрема приклади/будильник.мова
застосунки/        — окремі застосунки з програм (zastosunky.py); кожна тека
                     збирається в APK workflow-ом zastosunky.yml
```

## Байткод

Формат файлу `.байт` — JSON, як описано в ТЗ:
`{"версія": 1, "константи": [...], "код": [[опкод, аргумент], ...]}`,
плюс поле `"позиції"` (рядок/колонка для кожної інструкції — потрібно, щоб
VM могла показати помилку виконання з точним місцем у джерелі).

Опкоди з ТЗ реалізовані один в один (`PUSH_CONST`, `PUSH_VAR`, `STORE_VAR`,
`POP`, `ADD/SUB/MUL/DIV/MOD/NEG`, `EQ/NEQ/LT/GT/LTE/GTE`, `AND/OR/NOT`,
`JUMP`, `JUMP_FALSE`, `CALL`, `RETURN`, `CALL_NATIVE`, `HALT`). Додатково
введені (їх немає в мінімальному наборі ТЗ, але без них не працюють дії й
списки): `MAKE_FUNCTION`, `MAKE_LIST`, `INDEX_GET`, `INDEX_SET`, `SLICE_GET`;
у 0.5 — `MAKE_DICT`, `CONTAINS`, `GET_FIELD`, `SET_FIELD`, `MAKE_TYPE`,
`CALL_METHOD`, `TRY_BEGIN`, `TRY_END` (опис — у додатку ДОВІДНИК.md).

## Про `батарея()` / `датчик()` / `місце()`

Повертають словник (розпарсений JSON), а не голе число — так вимагає
розділ 7 ТЗ. Щоб дістати відсоток заряду:

```
хай інфо = батарея()
хай заряд = інфо["percentage"]      # або: інфо.percentage
```

## Відомі каверзні моменти

`у` — зарезервоване слово (частина `для x у список`), тому воно недоступне
як ім'я змінної (`хай у = 1` — помилка розбору). Це стосується лише
однобуквеного «у»; «уряд», «умова» тощо — звичайні ідентифікатори.

Імена вбудованих функцій (усе з `yadro/natives.py:ІМЕНА_NATIVE` — `друкуй`,
`вібруй`, `квадрат`, `коло`, ...) не можна перевикористати як ім'я власної
`дія`: компілятор завжди компілює виклик такого імені як `CALL_NATIVE`, тож
власна однойменна дія була б оголошена, але жодного разу насправді не
викликана — раніше це відбувалось мовчки. Тепер таке оголошення — явна
**помилка компіляції** з рядком і колонкою (`дія квадрат(...)` → «Не можна
оголосити дію «квадрат»: це ім'я вже зайняте вбудованою функцією»), а не
тихий no-op. Якщо власна логіка вже мала таку назву (наприклад, "квадрат" —
рахувати квадрат числа) — після додавання малювання доведеться перейменувати
(див. `квадрат_числа` у ПІДРУЧНИК.md).

Ще дві речі того самого штибу, з режимів креслення/ескізу:

- **`точка()`/`відрізок()` у запиті на ескіз стали `вузол()`/`сегмент()`** —
  ці імена вже зайняті `yadro/ekran.py` (термінальне малювання:
  `точка(x, y, колір)`, `відрізок(x1, y1, x2, y2, колір)`), причому для
  «точки» арність (3 аргументи) навіть збігається — тиха підміна значення
  замість помилки. Деталі — докстрінг `yadro/sketch.py`.
- **`покажи()`** визначено і в `малюнок.py`, і в `креслення.py` (та сама
  дія — «завершити й показати малюнок»), і **`довжина()`** — і в мовних
  вбудованих (список/рядок), і в `ескіз.py` (розмірна умова). Обидва
  випадки не перейменовані, а об'єднані у `yadro/vm.py`: `покажи()` дивиться,
  який стан ініціалізований (`полотно(...)` чи `аркуш(...)`), `довжина()`
  розрізняє виклики за кількістю аргументів (1 — список/рядок, 2 —
  сегмент+значення). Змішувати `малюнок`-режим і `креслення`-режим в одній
  програмі не передбачено, але жоден з них через це не стає недосяжним.
